# Data AI Data Analytics App

This application is designed to perform data processing, machine learning, and visualization tasks. It reads data from a CSV file, processes it, trains a machine learning model, and visualizes the results.

## Features

- **Data Processing**: Ingests, cleans, and transforms data for analysis.
- **Machine Learning**: Trains a linear regression model and evaluates its performance.
- **Visualization**: Plots histograms and scatter plots for data insights.

## Requirements

Ensure you have the following Python packages installed:

- pandas
- scikit-learn
- matplotlib
- pytest (for testing)

You can install these packages using pip:

```bash
pip install pandas scikit-learn matplotlib pytest
```

## Setup

1. Clone the repository:
   ```bash
   git clone <repository-url>
   cd data_ai_analytics_app
   ```

2. Place your data file in the root directory and name it `data.csv`.

## Usage

Run the main application script:

```bash
python main.py
```

## Testing

Run the tests using pytest:

```bash
pytest tests
```
